# ♟️ Proyecto Ajedrez

Juego de ajedrez en Java para dos jugadores que se ejecuta por consola.

> Proyecto académico realizado durante el ciclo de 1º DAM (Desarrollo de Aplicaciones Multiplataforma).

## 📋 Funcionalidades

- [Tablero de 8x8 con todas las piezas en su posición inicial]
- [Movimientos de cada pieza: peón, torre, caballo, alfil, dama y rey]
- [Validación de movimientos ilegales]
- [Turnos alternos entre blancas y negras]
- [Captura de piezas]
- [Jaque / jaque mate]


## 🛠️ Tecnologías

- **Lenguaje:** Java
- **Gestión del proyecto:** Maven (`pom.xml`)
- **Entorno de desarrollo:** IntelliJ IDEA
- **Control de versiones:** Git y GitHub
